# Inception Deck

## 概要

- インセプションデッキの概要と目的、それぞれの課題と取り組み方について記載しています。

## インセプションデッキとは

- インセプションデッキとは、プロジェクトやプロダクトの初期段階でチーム全員の認識を揃えるためのツールです。  
- プロジェクトの目的やゴール、課題、解決策などを整理し、共有することで、チームの方向性を明確にします。

## インセプションデッキの課題一覧

- インセプションデッキは、10個の手ごわい質問(俺たちの「Aチーム」を含めると11個)で構成されます。  
- インセプションデッキを埋めていくことで、プロジェクトに対する共通認識を、開発チームだけではなく、広範囲なプロジェクト関係者全員へ共有することができます。
- インセプションデッキの課題の一覧は以下の通り。

> [アジャイルサムライ > 3.5 インセプションデッキの課題一覧](https://amzn.asia/d/00HtzlYP)から抜粋

1. 我々はなぜここにいるのか

    ```txt
    何のために自分たちはチームを組むのか。自分たちの顧客は誰なのか。
    そもそもこのプロジェクトが始まった理由は何なのか。
    こうしたことを再確認する。
    ```

2. エレベーターピッチを作る

    ```txt
    30秒以内に2センテンスでプロジェクトをアピールするとしたら、
    何を伝えるべきだろうか？
    ```

3. パッケージデザインを作る

    ```txt
    何気なくめくった雑誌のページに、自分たちのプロダクトやサービスの広告が載っているとしたら、
    それはどんな内容がいいだろうか？それからもっと大事なのは、その広告を見た人は君のプロダクトを買いたくなるだろうか？
    ```

4. やらないことリストを作る

    ```txt
    プロジェクトで実現したいことというのはかなり明確になっているものだ。
    それと同じかそれ以上に、やらないことをはっきりさせよう。
    そしてそれをわかりやすく一覧にするんだ。
    ```

5. 「ご近所さん」を探せ

    ```txt
    「プロジェクトの関係者」に含まれる範囲というものは、自分たちが思っているよりもずっと広いものだ。
    そうした「ご近所さん」を招いて、コーヒーでもごちそうしながら自己紹介ぐらいしてもいいんじゃないだろうか。
    ```

6. 解決案を描く

    ```txt
    チーム全員の認識が揃っていることを確認するために、概要レベルのアーキテクチャ図を描こう。
    ```

7. 俺たちの「Aチーム」を編成する

    ```txt
    与えられたミッションをやり遂げるには、どんなチームが必要だろうか？それぞれのメンバーはどんな役割や責務を果たすべきだろうか？君にとって必要な「特攻野郎Aチーム」みたいなベストチームを説明しよう。
    ```

8. 夜も眠れなくなる問題は何だろう？

    ```txt
    プロジェクトで起きる問題のなかには、考えることすら恐ろしいものだってある。
    だが、あえてそうした心配事について話し合おう。どうすれば最悪の事態を避けられるだろうか？
    被害を最小限に食い止める方法はあるだろうか？
    ```

9. 期間を見極める

    ```txt
    どれぐらいの期間が必要なプロジェクトだろうか？
    3ヶ月？半年？それとも9か月？
    ```

10. 何を諦めるのかはっきりさせる

    ```txt
    プロジェクトにはいくつかの操作可能な要素がある。
    期間、スコープ、予算、それから品質。現時点で譲れない要素はどれだろう？
    譲ることになるのもやむを得ない要素はどれだろう？
    ```

11. 何がどれだけ必要なのか

    ```txt
    期間はどれくらいかかりそうか？コストは？
    どんなチームならプロジェクトをやり遂げられるだろうか？
    ```

## インセプションデッキ作成のイロハ

- 各インセプションデッキの課題に取り組む際の方法は問いません。**自由に議論し、チーム全員で合意形成を計ること**が重要です。
- 取り組み方の例として、「スライドを活用する方法」と、「このリポジトリを活用する方法」を記載します。

### スライドを活用する方法

1. [Googleドライブに保管されているインセプションデッキのテンプレート](TBD)にアクセス
2. テンプレートをコピーして案件用のインセプションデッキを作成する
3. 取り組みたいインセプションデッキの課題を選ぶ
4. 適宜、必要なインセプションデッキの課題に取り組む

### このリポジトリを活用する方法

1. 取り組みたいインセプションデッキの課題を選ぶ
   - [02_workshop_documents/images](./images)に各インセプションデッキの画像が格納されている
2. [02_workshop_documents](./)内に必要なファイルを作成し、必要なインセプションデッキの課題に取り組む
   - 例：
     - `01_why_are_we_here.md` のように、各課題に対応するMarkdownファイルを作成する
     - `01_why_are_we_here.drawio.svg` のように、各課題に対応するdraw.ioのファイルを作成する
